# Birthday Fund

A polished, open-source birthday contribution tracker. This frontend currently uses local demo state and is structured for a future Supabase backend.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Current frontend

- Dark indigo/blue visual system
- Interactive birthday selector
- Paid, pending and awaiting-verification states
- Pending members visible on the dashboard
- Payment submission modal with screenshot selection
- Interactive contribution filters
- Birthday timeline
- Responsive mobile layout

## Production roadmap

Supabase authentication, groups, database persistence, private screenshot storage, admin verification, advances/allocations, expenses and Vercel deployment.
